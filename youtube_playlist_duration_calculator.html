Before you calculate

Where do I get a YouTube Data API key?

Create a project in Google Cloud Console, enable YouTube Data API v3, then create an API key. For better security, restrict the key to the YouTube Data API. The key is required because a local HTML file cannot reliably read YouTube playlist data directly without an authorized API.

Will it count private or deleted videos?

YouTube only returns playlist entries and video details the API key is allowed to access. Private, deleted, region-restricted, or otherwise unavailable videos may not have a readable duration. The results will flag entries whose durations could not be retrieved, so the total is not falsely presented as complete.

Is anything stored or tracked?

No. This page does not save the API key or playlist URL, use cookies, load analytics, or include ads. When you calculate, the browser sends requests directly to Google's YouTube Data API. Your API key is included in those API requests.
